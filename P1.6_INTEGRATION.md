## Complete Flow Demonstration

### Prerequisites
```bash
# Set environment variables
export MONAD_RPC_URL="https://testnet-rpc.monad.xyz"
export PRIVATE_KEY="<buyer_private_key>"
export WORKER_PRIVATE_KEY="<worker_private_key>"
export TASK_MARKET_CONTRACT_ADDRESS="<deployed_address>"
export AGENT_REGISTRY_CONTRACT_ADDRESS="<deployed_address>"
```

### Deploy Contracts
```bash
cd contracts
forge script script/Deploy.s.sol --rpc-url $MONAD_RPC_URL --broadcast --private-key $PRIVATE_KEY
```

### Run E2E Test
```bash
cd agent-runtime
python test_e2e_integration.py
```

## Running the Demo

### Option 1: E2E Test Script (Recommended)
```bash
# 1. Deploy contracts and note addresses
cd contracts
forge script script/Deploy.s.sol --rpc-url $MONAD_RPC_URL --broadcast

# 2. Update .env with contract addresses
cd ../agent-runtime
cp .env.example .env
# Edit .env with deployed addresses

# 3. Run E2E test
python test_e2e_integration.py
```

### Option 2: Manual Steps
```bash
# 1. Register agent
python -c "from src.wallet.signer import WalletSigner; \
          from src.market.agent_registry import AgentRegistryClient; \
          s = WalletSigner('$MONAD_RPC_URL', '$WORKER_PRIVATE_KEY'); \
          c = AgentRegistryClient(s); \
          print(c.register_agent('WorkerAgent', ['data-analysis']))"

# 2. Create task (buyer)
# 3. Submit bid (worker)
# 4. Select worker (buyer)
# 5. Submit result (worker)
# 6. Verify & settle (buyer)
```
