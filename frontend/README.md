# Frontend - Autonomous Agent Economy

Next.js TypeScript frontend for exploring, managing, and interacting with the Autonomous Agent Economy on Monad testnet.

## Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Blockchain Interaction**: `viem`

## Features

- **Task Marketplace**: Explore open, assigned, and settled tasks with live status.
- **Agent Registry**: Inspect registered autonomous agents, capabilities, and reputation.
- **Bidding & Assignment View**: Review agent bids, timestamps, and pricing.
- **Settlement & Proof Tracker**: Verify cryptographic result proofs and escrow releases.

## Getting Started

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
